# PRD 可选章节模板

复杂需求 / 多方案未决 / 内审场景，PM 按需 copy 模板插入 PRD 的 §1.5 用户角色 后、§2 场景地图 前作为 §1.6 / §1.7。简单迭代需求不用插。

骨架 `gen_prd_skeleton.py` 默认不生成这两章——PM 觉得需要时从本文件 copy 进 PRD md。

---

## 可选章节 A · 竞品调研

**何时用**：

- 项目首次涉足某场景（新功能、新模式）
- 内审讲解顺序要求竞品参照（[内审准入](https://INTERNAL_URL_REDACTED L113「背景&目标 → 竞品调研及总结 → 思路&框架」）
- 决策依据需向 leader / 评审会说明「为啥不抄 Binance」

**何时不用**：

- 已有 competitor-analysis skill 产物且决策已落地 → PRD 里只写「沿用 [competitor-XX-YYYY-MM-DD.md](./competitor-XX-YYYY-MM-DD.md) 结论，本期借鉴点 A / B / C」
- PRD 单纯迭代已有功能，无新竞品方向需要参照

**模板（copy 后改 §1.6 编号）**：

```markdown
## 1.6 竞品调研

**业务故事**：（≤ 30 字，讲谁 / 做什么 / 为什么）

### 1.6.1 调研范围

至少覆盖以下主流竞品（聚焦功能主流程的交互路径与核心逻辑）：

| 竞品 | 调研范围 | 截图链接 |
| :--- | :--- | :--- |
| Binance | 入口 / 主流程 / 异常态 | [./assets/competitor-binance-*.png](./assets/competitor-binance-*.png) |
| OKX | 入口 / 主流程 / 异常态 | [./assets/competitor-okx-*.png](./assets/competitor-okx-*.png) |
| Bybit | 入口 / 主流程 / 异常态 | [./assets/competitor-bybit-*.png](./assets/competitor-bybit-*.png) |
| Bitget | 入口 / 主流程 / 异常态 | [./assets/competitor-bitget-*.png](./assets/competitor-bitget-*.png) |
| Gate | 入口 / 主流程 / 异常态 | [./assets/competitor-gate-*.png](./assets/competitor-gate-*.png) |

### 1.6.2 核心结论

- 结论 1（一句话说清竞品做法的共性）
- 结论 2（差异点）
- 结论 3（成熟度对比）

### 1.6.3 借鉴点

- 借鉴 1：本期采纳 XX 做法，理由：XX
- 借鉴 2：本期采纳 YY 做法，理由：YY

### 1.6.4 差异决策

- 差异 1：不抄 XX 做法，理由：XX（如不符合本平台用户心智 / 合规要求 / 成本过高）
- 差异 2：不抄 YY 做法，理由：YY

### 1.6.5 详细调研产物

完整截图 / 流程拆解 / 全量对比表见 [competitor-{项目}-YYYY-MM-DD.md](./competitor-{项目}-YYYY-MM-DD.md)。
```

## 可选章节 B · 多方案对比

**何时用**：

- 本期有 2+ 候选方案，技术路径有重大分歧
- 需要向 leader / 评审会说明为何选 A 不选 B
- 内审 L80「若有多个方案，给出决策因素及建议」要求

**何时不用**：

- 单方案需求
- 方案在 baseline 决策章 / delta §6 已收敛无歧义，PRD 直接落最终态

**模板（copy 后改 §1.7 编号）**：

```markdown
## 1.7 多方案对比

**业务故事**：（≤ 30 字，讲谁 / 做什么 / 为什么）

### 1.7.1 备选方案

- **方案 A**：一段描述 + 核心机制
- **方案 B**：一段描述 + 核心机制
- **方案 C**：一段描述 + 核心机制（如有）

### 1.7.2 决策因素

| 维度 | 方案 A | 方案 B | 方案 C |
| :--- | :--- | :--- | :--- |
| 开发成本 | 高 / 中 / 低 | 高 / 中 / 低 | 高 / 中 / 低 |
| 用户体验 | 描述 | 描述 | 描述 |
| 数据合规 | 描述 | 描述 | 描述 |
| 上线时效 | X 周 | Y 周 | Z 周 |
| 长期可扩展 | 描述 | 描述 | 描述 |

### 1.7.3 推荐方案

**推荐方案 X**。理由：

- 理由 1
- 理由 2
- 理由 3

### 1.7.4 否决理由

- 否决方案 Y：理由 XX
- 否决方案 Z：理由 YY
```

## 插入位置示意

```
1. 项目背景与目标
  1.1 现状分析
  1.2 价值论证
  1.3 目标 + 成功指标
  1.4 核心变更
  1.5 用户角色
  1.6 竞品调研           ← 从本文件 copy 进来
  1.7 多方案对比          ← 从本文件 copy 进来
2. 场景地图
3. ...
```

`check_prd_md.sh` 不强制检查 §1.6 / §1.7 存在性，加上即检查格式 / 讲人话规则等。
