# PRD 可选章节：竞品参考 / 多方案对比

骨架不生成这两节，需要时复制下面的模板，加在 §1 概述末尾（delta 编为 `## 1.1` / `## 1.2`；旧 12 章 PRD 编为 `## 1.6` / `## 1.7`）。

## 什么时候加

| 章节 | 加 | 不加 |
| :--- | :--- | :--- |
| 竞品参考 | 首次做某类功能；评审需要说明参考了谁、为什么不照搬；输入里给了竞品材料 | 迭代已有功能、没有新的竞品方向；输入里没有竞品材料（不自己编竞品做法） |
| 多方案对比 | 输入里有 2 个以上候选方案，且已选定或待 PM 选 | 只有一个方案；方案早已定死 |

已有 competitor-analysis 产物时，竞品参考只写结论和借鉴点，详细内容链接过去。

## 模板 A：竞品参考

```markdown
## 1.1 竞品参考

| 竞品 | 怎么做 | 本轮是否借鉴 |
| :--- | :--- | :--- |
| Binance | 一句话说它的做法 | 借鉴 / 不借鉴 |
| OKX | 一句话 | 借鉴 / 不借鉴 |

- **借鉴**：采纳了哪个做法，原因（输入里给的）
- **不照搬**：哪个做法不采用，原因（输入里给的）
- **详细调研**：[competitor-{项目}-YYYY-MM-DD.md](./competitor-{项目}-YYYY-MM-DD.md)
```

示例（直播策略卡，参考抖音带货直播间）：

```markdown
## 1.1 竞品参考

| 竞品 | 怎么做 | 本轮是否借鉴 |
| :--- | :--- | :--- |
| 抖音带货直播间 | 主播同时挂多个商品，讲解中的那件高亮，观众可横滑翻看 | 借鉴 |
| 抖音带货直播间 | 商品下架直接消失，不留占位 | 借鉴 |

- **借鉴**：多卡同时在架 + 讲解中高亮，观众一次看一张、横滑翻看
- **不照搬**：抖音点商品弹购物车浮层；本轮点卡打开交易组件，不加中间层
```

## 模板 B：多方案对比

```markdown
## 1.2 方案对比

| | 方案 A：一句话名称 | 方案 B：一句话名称 |
| :--- | :--- | :--- |
| 做法 | 一两句 | 一两句 |
| 开发成本 | 输入里给的估算 | 输入里给的估算 |
| 用户体验 | 差别在哪 | 差别在哪 |
| 风险 | 输入里提到的 | 输入里提到的 |

**结论**：选方案 A（或「待 PM 选」，并把它写进 §1 待确认）。理由：输入里给的理由。
```

规则：

- 表里每一格都来自输入；输入没给的那格写「未评估」，不自己估成本、工期
- 选定方案后，§2 只写选中的方案，不再写落选方案的规格
- 选型理由只写在这里，§6 决策章不再重复
