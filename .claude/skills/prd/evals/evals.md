# PRD Skill Eval 集

> 改 prd SKILL.md 行为塑形段前，先跑这 5 个任务（派 sub-agent，禁读 session-state.md）。
> 对照组：不加载 SKILL.md 跑同一任务 → 比较差异。
> 判分 rubric：每条命中维度给 ✅（遵守）/ ❌（违反）/ ⚠（部分）。

## 任务 1：裸编号 + 章节锚点（硬规则 ②）

**输入**：给一段含 `A-1 / B-2 / §5.1` 的 delta 正文，要求改 PRD 场景引用段。
**判 rubric**：
- [ ] 正文无裸编号 `A-1 / B-2`（标题 / 表格 / 截图名 / 埋点名除外）
- [ ] 正文无 `§X.Y` 锚点（单文件豁免，split 才拦）
- [ ] 跨章引用用「章节号 + 白话名」或纯白话名

## 任务 2：snake_case 技术黑话（硬规则 ①）

**输入**：给一段含 `trtc_enabled` / `card_id` / `getSubscriberCount` 的 delta §3.2，要求改写。
**判 rubric**：
- [ ] §3.2 字段名用中文业务名（「主播 TRTC 标志」非 `trtc_enabled`）
- [ ] 无 JS 事件 / DOM API / 框架状态词
- [ ] 埋点章事件英文名保留（唯一例外）

## 任务 3：长句 + 分号串 + bullet 句号（WARN 三件套）

**输入**：给一段 5 句号 / 4 分号焊一行的 bullet，要求拆。
**判 rubric**：
- [ ] 拆后一行 ≤ 2 分号
- [ ] 句段 < 100 字
- [ ] bullet 句号只落行尾
- [ ] 没用逗号 / 顿号绕检测（换标点凑过 = 仍 ❌）

## 任务 4：delta §6 决策段复述（语义去重 ①）

**输入**：给一段 §6 决策段复述 §2 已有的交互流程 + 字段下发。
**判 rubric**：
- [ ] §6 只写 WHY / 否决 / 取舍，不复述 §2 WHAT
- [ ] 删了不影响读者从 §2 获取事实的段落
- [ ] 无「背景：审视 V1 发现」流水过程描述

## 任务 5：Confluence 推送违规（硬规则 ⑥⑨⑩）

**输入**：给一段含 `---` 水平线 + `> 引用块` + `mermaid` 源码的 PRD 正文。
**判 rubric**：
- [ ] 无单独成行 `---`
- [ ] 无 `>` 引用块（baseline 例外除外）
- [ ] 无 mermaid / PlantUML 源码
