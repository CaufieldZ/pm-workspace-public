# 行业真实中文宣发样本（OKX / 币安 / Bitget）

> Step 1 必读。佳作库回答「哪种关系成立」，这份回答「真实交易所的中文宣发读起来是什么样」——语感、颗粒度、该放多少硬事实。
>
> **取写法，不取句**：学的是结构与颗粒度，句子本身是别家的，不搬进产物。功能事实一律以本方 PRD 为准。
>
> 采集于 2026-10-23（OKX 中文 TG 频道近 500 帖、币安中文公告频道近 500 帖、Bitget 帮助中心「产品更新」10 篇），复采方法见 §四。

## 一、三家各自的语域

| 渠道 | 语域 | 典型结构 |
|---|---|---|
| OKX 中文 TG / 社群 | 社媒短帖，口语、用户黑话 | 痛点一两句 → 「功能名」上线 → 3 条「短标签 - 硬事实」→ 版本号 / 入口路径 |
| 币安中文公告 | 正式公告，第三人称 | 地区声明 → 亲爱的用户 → 「推出 X，帮助用户 Y」→ 功能亮点列表 → 详情链接 → 免责声明 |
| Bitget 帮助中心 | 产品更新说明，问答体 | 「为了帮助您 Y，现已正式上线『X』」→ 它能帮你做什么？→ 怎么开启 → 注意事项 |

## 二、样本（节选原文 · 每条后面是要学的地方）

**OKX Wallet 智能账户**（OKX 中文 TG，2026-01-21）

```
链上冲狗最痛苦的不是买不到卖不出，是：
反复弹签名、买完才想止盈止损、想快又不敢把私钥交出去。

OKX Wallet「智能账户」全面上线：
自托管不变 - 私钥加密存于 TEE，仍然是去中心化
策略交易直接上 - 限价单 / 止盈/ 止损 / 跟单
操作更顺 - 静默签名自动激活，一键买卖

请更新 App 至 6.155 版本体验
```

学：痛点是**三个具体的麻烦**，用目标用户自己的词（冲狗、弹签名）；卖点是「短标签 - 事实」，事实里有品类清单；CTA 给版本号。

**同一功能的第二帖**（2026-01-22）

```
不盯盘，也能自动止盈止损吗？
买入那一刻就把"卖出计划"一起设好：
 ·止盈/止损触发自动卖出
 ·限价单自动成交
 ·预设策略一键选：翻倍出本 / 跌半全卖

少盯盘，少手忙脚乱。
```

学：「翻倍出本 / 跌半全卖」是交易者自己的说法，一读就懂；全篇只有收尾一句是修辞句，且很朴素。

**OKX 智能组合**（2026-09-10）

```
OKX 上线「智能组合」策略，拥有你的私人 ETF
看好的标的很多，难的是把它们变成一个按比例被管理的组合：涨跌之后比例会偏离最初设计……
现在可以把这些资产放进同一篮子，权重你定，偏离就自动再平衡。
入口：OKX 首页 - 交易 - 策略&跟单 - 智能组合
```

学：标题借用户**已经懂的概念**（ETF）做类比，不自造比喻；结尾给完整入口路径。

**币安杠杆 · 追加保证金提醒**（币安中文公告，2025-03-19）

```
币安杠杆现已推出自定义追加保证金风险率及提醒频率功能，帮助用户灵活高效地管理持仓风险。
* 自定义追加保证金提醒频率
    * 支持设置每 1 小时、4 小时、12 小时和 24 小时的提醒频率。
```

学：卖点落到具体档位（1 / 4 / 12 / 24 小时），不写「更灵活」就停。

**Bitget App 跟单体验全新升级**（Bitget 帮助中心，2026-10-22）

```
此前，用户需要切换至单独的跟单页面，才能查看排行榜和管理跟单计划，导致操作流程不连贯。
现在，跟单功能已整合至 App 底部导航栏的"交易"标签页……您的资产卡片、排行榜和跟单中心现在均可在同一屏幕中查看。
```

学：「此前……现在……」是最朴素的对照，两端都是用户看得见的界面事实。

**Bitget CFD 跟单 · 追踪出场**（2026-08-18）

```
为了帮助您在跟单交易中更轻松地锁住利润、控制风险，告别时刻盯盘的焦虑，
Bitget CFD 跟单系统现已正式上线「追踪出场」功能
```

学：开头一句交代「为谁解决什么」，然后点功能名；后文全是规则与数字（5%～99%、约 10 秒检测一次）。

**合规行**（三家都有）

- 币安每帖首行：「这是一般性公告，此处提及的产品和服务可能不适用于您所在的地区。」
- OKX 活动帖末：「本内容仅供参考，不构成投资建议……数字资产涉及高风险，历史收益不代表未来表现……请依据自身情况谨慎决策并遵守当地法规。」

## 三、真实写法 vs AI 味写法

| 真实交易所怎么写 | AI 味长什么样 |
|---|---|
| 痛点列**具体的麻烦**，用目标用户的黑话（冲狗 / 弹签名 / 盯盘） | 痛点写成抽象处境（「总是手忙脚乱？」「信息太多看不过来？」） |
| 卖点 =「短标签 - 硬事实」：数字、档位、品类清单 | 每条卖点都是一句修辞（「X，Y」对仗 / 「替你……」） |
| 借用户已懂的概念类比（私人 ETF、翻倍出本） | 自造比喻（「成本归到一条线」「账替你算」） |
| CTA 给版本号或入口路径 | 「立即打开 App 体验！」 |
| 修辞句一篇最多一句，放标题或收尾 | 通篇对仗，每句同一个形状 |
| 句子长短不齐，有的十几个字带冒号和清单 | 每句都卡在 14～20 字、节奏整齐 |

**判法**：把一段文案里的修辞句（对仗、拟人、比喻）数一遍——超过一句，先砍成事实句再看。海报主副标题这种一句话位置是例外，那里修辞就是它的职责（见 SKILL.md 载体语域契约）。

## 四、复采方法

样本过时（超过半年）或要找某类功能的对照时，按下面重采，新样本按 §二 的格式补进来：

- **OKX / 币安中文 TG**：`curl -s https://t.me/s/OKXAnnouncements_CN`、`https://t.me/s/binance_cn`，翻页用 `?before={最小帖号}`，帖子正文在 `tgme_widget_message_text` 节点里。
- **Bitget 帮助中心**：`curl -s -A "Mozilla/5.0 ..." https://www.bitget.com/zh-CN/support/articles/{id}`（带浏览器 UA，服务端直出正文），「产品更新」栏目的文章 id 从任一文章页的相关链接里拿。
- **走不通的**：WebFetch 只回摘要、引文不超过 125 字，拿不到原文，用 curl；X / 微信公众号要登录，抓不到。
