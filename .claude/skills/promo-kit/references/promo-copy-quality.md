# 宣发文案质量标准（promo-kit）

> 这份文件回答「什么算好」。它是**常驻的正面标准**，不是一次性的竞品检索——每批交付后把人类放行过的句子回灌进来，库越用越准。
>
> **入库门槛：只收人类明确放行过的句子。** 模型自己觉得好的不收——本文件的全部价值就在这条门槛上。

## 一、六种关系（一句话位置）

一句话位置（视频开场、图文主标、海报主副标题、短文案标题）的合格形态，是两段之间构成下面六种**关系**之一。

**关系不是字数形状。**「四字，四字」只是外形；写的是什么关系，才是这句成不成立的地方。只规定形状、不定义关系，交上来的就是形状——「一点申请，开口就聊」4+4 齐整，两段却是**顺承**（先申请，然后就聊上了），第二段没带来任何新信息。

| 代号 | 关系 | 长什么样 | 例 |
|---|---|---|---|
| 分工 | 两个主体各自的独立动作 | **「你」的动作不蕴含「我」的动作**，两半互不派生 | 赚没赚，账替你算（书面范例） |
| 位移 | 从 X 到 Y，位置变了 | 「从…到…」，或隐含的迁移；两端是**用户自己的两种状态**，不是「机械动作 → 到达」 | 从旁观到开口，只差一次举手（已放行） |
| 对照 | 旧状态与新状态并置 | 常省略共同谓语：前段说旧，后段只说「不」 | 弹幕会刷走，声音不会（已放行） |
| 并列 | 两件独立的事 | 双否定，或枚举＋四字收尾 | 行情不切，对话不断 ／ 看盘、发言、送礼，一样不少 |
| 在场 | 句子里有第二个人 | 你的东西被对方接住 | 你的问题，主播听得见 ／ 举个手，主播就听见 |
| 落点 | 数字后面接人的动作 | 不是数字＋系统状态 | 八位嘉宾，各抒己见（已放行） |

> **表里的例子只放两类**：人类明确放行过的句子（标「已放行」），和本文件自带的书面范例（标「书面范例」）。**模型产出即使判据全过也不进这张表**——曾经放过一条对照实验的句子，结果是它恰好就是某个测试功能的答案，反而把那条功能的自然写法整条封死（产出报告：那条轴被"整条封掉"了）。判据通过的句子不是标准，被人类放行过的才是。
>
> **「分工」一行没有已放行实例**，只有书面范例——它是六种关系里唯一没被真实交付验证过的，最需要下一批交付来补。

### 怎么选

关系由**卖点的语义类型**决定——语义决定了它最容易掉哪个坑，也就决定了该往哪个关系改。完整对照见下节。

连接点（Step 2）定「写什么」，关系定「怎么搭」，两者配对使用。

## 二、按卖点语义的改写对照表

下表每一行的「失败形态」都是**实测到的**（无指引对照，n=5），不是假想。

| 卖点语义 | 最容易写成 | 改写成 | 实测 |
|---|---|---|---|
| **委托型**（提醒 / 代管 / 自动） | 顺承 | **分工** | 「开播提醒」5 次独立产出全部落到分工，全部合格 |
| **因果型**（直达 / 一键 / 秒到） | 顺承 | **位移** | 「一键直达」5 次全部写成顺承，全部降档——**因果型是最难的一类** |
| **并行型**（不影响 / 同时可用） | 通用维护语（照旧可用 / 一屏搞定） | **并列** | — |
| **数量型**（N 位 / N 人） | 数字＋系统位置（同时在麦） | **落点** | — |
| **状态型**（多人 / 同台） | 系统状态 | **在场** | — |
| **感受型**（不慌 / 从容 / 安心） | 抽象评价（稳健入门 / 一目了然） | **对照** | — |

因果型为什么最难：卖点本身就是一条因果链（点 → 到），最省力的写法就是把这条链抄下来。**必须换关系，不是换措辞**——「点开提醒，人就到了」改成「点开提醒，你就在现场」仍是顺承，实测有 run 以为改对了。

## 三、两条降档 + 可替换性

**顺承**：第二段是第一段的必然结果。形状上四字对四字样样齐全，关系上第二段无新信息。

**机制**：写产品怎么实现（默认静音 / 席位 / 排队 / 审批 / 上限）。读者知道了产品怎么工作，不知道自己会落在什么画面里。这类词是正文类载体的料，留给短文案中段与 Square 卖点列表。

**可替换性**（自检判据）：把功能名抽掉，这句话还成立吗？

| 句子 | 抽掉功能名后 | 判定 |
|---|---|---|
| 稳健入门 | 任何功能都成立 | 通用句 |
| 一目了然 | 任何数据展示都成立 | 通用句 |
| 一点申请，开口就聊 | 任何「申请即用」都成立 | 通用句 |
| 上麦期间照旧可用 | 任何「不影响其他功能」都成立 | 通用句 |
| 弹幕会刷走，声音不会 | 只有语音连麦能这么说 | 专属句 |
| 看盘、发言、送礼，一样不少 | 只有「麦上还能看盘」能这么说 | 专属句 |
| 八位嘉宾，各抒己见 | 只有多人同台能这么说 | 专属句 |

**唯一例外**：当「为某类人设计」本身就是卖点时（模拟盘对新手说「新手友好」），通用是刻意的，不判降档。

**位移类句子的补充测法**：位移句的两端常是场景对象（「从手机通知，到直播间里」），抽掉功能名照样通顺，可替换性判据在这里失效。改问一句：**换个功能之后，这半句还指得着同样的那两个对象吗？**指不着，就是专属句——「手机通知」与「直播间」这两个端点只在「从提醒直达」这条链上同时成立。

### 假阳性豁免（判降档前先看这一节）

下面几种句式**在别的写作标准里是禁句**，但在广告短句位是刻意装置——**孤立出现不判降档，成簇才算问题**。写这一节是因为差点踩过界：`stop-slop`（17.3k★ 的去 AI 味 skill）明令禁对比结构（「Not X. It's Y.」）与三项并列（「Three-item lists → Use two items or one」），机械套用会直接毙掉本文件里的好句。

| 句式 | 别人为什么禁 | 我们为什么留 |
|---|---|---|
| **对照**（「弹幕会刷走，声音不会」） | `stop-slop` 禁的是**否定→揭示**式：「Not X. It's Y.」「Not a X… Not a Y… A Z.」——拿否定当铺垫，最后给一个断言 | 我们的对照是**肯定＋否定并置、且不揭示**：前段说旧事实，后段只说「不」，不做铺垫-揭晓那一步。不在它的清单里 |
| **并列 / 双否定**（「行情不切，对话不断」） | 同上，属它列的「Negative Listing」 | 两段都停在否定、不收敛到断言，与「否定堆叠到揭示」是两种结构 |
| **三项并列**（「看盘、发言、送礼，一样不少」） | `stop-slop`：「Three-item lists → Use two items or one」 | 它的分析单元是**散文句**（通篇例句都是文章里的句子）。三项并列在散文里是 AI 味，在 14 字广告句里是节奏装置 |

**成簇判据**：**数「具体句式形状」，不数关系代号**——同一个关系可以用很多种句式写，「对照」出现三次不必怀疑，但「X 会 Y，Z 不会」这一种形状出现三次就是模板。阈值 **3 次以上**才开始怀疑。

判法：把同组句子并排看，能一眼看出版式相同（同一骨架只换词）才算一次。两个口径都数一遍更稳（本文件被 3 个产出同时要求过定义，说明这条容易含糊）。

**不豁免的**：顺承、机制词、通用句——这三条没有例外，任何位置命中即重写。

## 四、佳作库

> **入库门槛：只收人类明确放行过的句子。** 每条标注来源与关系代号，方便按关系取用。
>
> **用法：取关系，不取句。** 库的价值在「这句用了哪种关系、为什么生效」，不在句子本身。学走关系之后，**换一个本功能自己的连接点重写**——照抄、或把库句的主语顺序调一下就交上来，都算降档。这条不是预防性提醒：实测有产出主动弃掉了 3 个候选，理由都是与原句「几乎同句」；也有产出报告说库里的句子把某条轴「整条封掉」，被迫换轴重写。范例会传播形状，这是本文件最容易失效的地方。

| 句子 | 关系 | 来源 |
|---|---|---|
| 从旁观到开口，只差一次举手 | 位移 | 多人连麦海报 · 总览副标题（人类放行） |
| 你的问题，主播听得见 | 在场 | 多人连麦海报 · 海报 2 主标题（人类放行） |
| 弹幕会刷走，声音不会 | 对照 | 多人连麦海报 · 海报 2 副标题（人类放行） |
| 八位嘉宾，各抒己见 | 落点 | 多人连麦海报 · 海报 3 主标题（人类放行） |
| 一场直播，听见不止一个声音 | 落点 | 多人连麦海报 · 海报 3 副标题（人类放行） |
| 行情不切，对话不断 | 并列 | 多人连麦海报 · 海报 4 主标题（人类放行） |
| 看盘、发言、送礼，一样不少 | 并列 | 多人连麦海报 · 海报 4 副标题（人类放行） |
| 赚没赚，账替你算 | 分工 | 现货成本价示例（书面范例） |
| 摊薄价旁边多一条线，赚没赚不用再估 | 对照 | 现货成本价示例（书面范例） |

**回灌规则**：每批交付后，把用户明确认可的句子按「句子 / 关系 / 来源」追加进来。不用等攒够——一句也收。

## 五、喜好与禁区

写成「X，不是 Y」——只说「要专业友好」等于没说，因为每个产品都这么讲。

**喜好**

- **具体，不是抽象**——「摊薄价旁边多一条线」，不是「一目了然」
- **有人，不是系统**——「主播听得见」，不是「支持语音上麦」
- **对照，不是顺承**——「弹幕会刷走，声音不会」，不是「点开就到」
- **口语的节奏，不是书面报告**——「赚没赚，账替你算」，不是「清晰感知账户运行逻辑」

**禁区**

- 抽象形容词充数：更快 / 更省心 / 更方便 / 更安全 / 稳健 / 一目了然 / 清清楚楚
- 机制词进一句话位置：默认静音 / 席位 / 排队 / 审批 / 上限
- 顺承句：点开就到 / 一点就进 / 提醒一响，人在现场
- 通用句：抽掉功能名后照样通顺的任何一句
- 内部语域：报告腔、说明书画风（「账户运行逻辑」「操作流程」）
