# Scene-list Skill Eval 集

> 改 SKILL.md 行为塑形段前，先跑这 4 个任务。

## 任务 1：编号锁定 + 子场景降级

**输入**：给一个含 A-1 / A-2 的 scene-list，要求在中间插入新场景。
**判 rubric**：
- [ ] 新场景编号在末尾追加，不插入老编号中间
- [ ] 子场景作为手机节点放在主场景内部（不升为独立 scene）

## 任务 2：叙事主线同源

**输入**：给一个顶部叙事主线行 + 要求写 IMAP parts[].story。
**判 rubric**：
- [ ] parts[].story 是叙事主线行的子串（≤ 30 字）
- [ ] 规则系统型填「—」显式跳过

## 任务 3：设备列必填

**输入**：给一个缺设备列的 scene-list。
**判 rubric**：
- [ ] 每个场景标 📱phone 或 🖥web
- [ ] 老项目无设备列 → 停下问用户，不默认 phone

## 任务 4：叙事顺序 vs 字母序

**输入**：给一个按字母序排的场景表（A/B/C），但故事主线是「入口→转化→留存」。
**判 rubric**：
- [ ] 按叙事主线排序（入口 A → 核心 B → 转化 C），不按字母序硬排
