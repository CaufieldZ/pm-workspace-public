# 竞品分析 · Markdown 输出结构示例

三套结构，按调研要回答的问题选：

- **范式 A · 决策型**（默认）：要回答「各家怎么做、我方改什么」。结论先行，对比用事实表，建议写成可开发的规则。
- **范式 B · CRBE 深度版**：用户说「立项调研 / 战略对标 / 深挖」。逐功能拆五层 + CRBE 四维。
- **范式 C · 打分对比型**：要回答「谁强谁弱、我方整体排第几」。1-9 分打分矩阵 + 截图&说明表。

排版铁律：禁用 `---` 水平分隔线（Confluence 渲染崩），用 `##` 标题或空行分隔；全角标点；打分缺证据标「—」不硬凑。

## 范式 A · 决策型（默认）

样例：`projects/community/deliverables/comp-community-price-card-2026Q4.md`（社区交易导流组件竞品调研，Confluence pageId 199044664）。

## 三、功能点打分对比矩阵

先给每家一句话定位（加粗平台名 ＋ 定性判断，领导范式）：

- **{竞品 A}**：一句话定性（最强 / 最朴素 / 激励最激进…）

## 范式 B · CRBE 深度版（立项调研 / 战略对标）

在范式 C 的基础上，功能拆解章改为逐功能拆五层，并补 CRBE 四维 + 反向结论 + 翻车预警。

**单功能五层拆解**：

```markdown
### 2.1 {功能名称}

**设计方案**：交互流程、页面结构、信息架构，引用截图
**设计意图**：为什么这么设计、服务什么业务目标、能追问「为什么是 X 不是 Y」的拆一层
**优点 / 缺点**：设计好 / 差在哪
**三角对比**：入口位置 / 交互步骤 / 信息密度 / 核心差异（竞品 vs 基准竞品 vs 我方）
**借鉴价值**：能学什么 ＋ 直接抄的翻车风险
**我方进度**：🟢🟡🔵🔴⚫ ＋ 具体说明
**建议**：加粗一句，落到我方动作 ＋ 优先级
```

**CRBE 四维**（核心章）：

- **C**apability 能力拆解：逐项标 ✅可复制 / ❌不可复制 / ⚠️路径红利 / 💎差异化机会
- **R**oute 路径分析：竞品怎么走到今天、路径依赖是什么、我们能不能走同一条路
- **B**arrier 壁垒识别：网络效应 / 数据积累 / 品牌认知，逐项判断我方能否突破
- **E**fficiency 效率对比：同任务竞品几步、我方几步，转化漏斗各环节差异

**反向结论**：🚫 不该学的 3 件事 ／ 🧩 可借鉴的底层逻辑 ／ 💡 差异化机会。

**翻车预警**：产品 / 用户 / 技术 / 运营 / 成本 五层风险表。

## 通用铁律（三套范式都守）

- 未公开数据不编造，标「未公开，需验证」
- 打分矩阵缺证据的格标「—」，不拍脑袋填分
- 竞品「没有 / 不支持」类断言先查证，别想当然否定竞品价值
- 涉及我方现状的判断回读 baseline / PRD，不凭印象脑补
- 对比格只用 ✅ + 做法 / ❌（确认没有）/ 未见（没看到）
- 举例只用截图或原文里的真数字，无依据的阈值写「需要拍板」
- 正文不出现人名，不写口号式总结句，不给竞品打法起名字
- 反向结论 ≥ 正向结论
