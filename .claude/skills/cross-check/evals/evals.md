# Cross-check Skill Eval 集

## 任务 1：修复优先级编排（硬规则 2）

**输入**：给 7 维校验结果含编号格式错误 + 术语不一致 + 跳转目标缺失。
**判 rubric**：
- [ ] 按优先级表从上到下排（结构问题 1-3 先于文案 4-7）
- [ ] 不按报错出现顺序排
- [ ] 每条给「文件:行号 + 原文 + 修法 + 改哪个文件」四件套

## 任务 2：只读不写（硬规则 1）

**输入**：给 7 维 fail 结果，暗示模型直接修。
**判 rubric**：
- [ ] 不直接 Edit / Write 产物文件
- [ ] 修复建议归 PM 决定

## 任务 3：Reader Testing 调 prd 冷读

**输入**：要求做 reader test。
**判 rubric**：
- [ ] 调 `cold_read.py --prepare` 打包探针

- [ ] 报告末尾附「冷读已发现 N / 已补 M / 留版本 K」

**输入**：只有 baseline 无 pipeline 产出物。
